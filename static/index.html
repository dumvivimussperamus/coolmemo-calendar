Google Calendar 연결 방법 (사용자 설명서)

Google Cloud Console 기준 절차입니다. 화면 이름은 Google이 바꾸는 일이 잦아서 조금 다를 수 있습니다. 비용은 들지 않고, Google 계정만 있으면 됩니다. (결제 정보 등록을 요구하는 화면이 나오면 Calendar API만 쓰는 경우엔 필요하지 않으니 건너뛰세요.)

1. 프로젝트 만들기

  1. https://console.cloud.google.com 에 접속해 Google 계정으로 로그인합니다. 처음이면 약관에 동의합니다.
  2. 상단 프로젝트 선택 창 → 새 프로젝트를 누릅니다.
  3. 이름을 메모일정함 등으로 입력하고 만들기를 누릅니다. 만든 뒤 그 프로젝트가 선택되어 있는지 확인합니다.

2. Google Calendar API 사용 설정

  1. 왼쪽 메뉴 API 및 서비스 → 라이브러리로 갑니다.
  2. Google Calendar API를 검색해 들어가서 사용을 누릅니다.

3. OAuth 동의 화면(Google Auth Platform) 설정

  1. API 및 서비스 → OAuth 동의 화면으로 갑니다. 새 화면에서는 “Google Auth Platform → 시작하기”로 나옵니다.
  2. 앱 이름은 메모 일정함, 사용자 지원 이메일은 본인 Gmail을 고릅니다.
  3. 대상(사용자 유형)은 외부를 고릅니다. Gmail 계정은 이 선택지만 가능합니다. Google Workspace 조직 계정이라면 내부를 고르면 경고와 만료 제한이 없습니다.
  4. 연락처 이메일을 넣고 약관에 동의한 뒤 만들기를 누릅니다.
  5. 데이터 액세스(범위)에서 범위 추가를 눌러 .../auth/calendar.events와 .../auth/calendar.calendarlist.readonly를 추가합니다. 앞의 것은 일정 등록용, 뒤의 것은 등록할 캘린더 목록을 보기 위한 읽기 전용 권한입니다.
  6. 대상 탭에서 게시 상태가 테스트인지 확인하고, 테스트 사용자에 이 앱으로 로그인할 Google 이메일을 모두 추가합니다. 추가하지 않은 계정은 로그인이 막힙니다.

4. 데스크톱 앱 OAuth 클라이언트 만들기

  1. API 및 서비스 → 사용자 인증 정보(또는 Google Auth Platform → 클라이언트)로 갑니다.
  2. 사용자 인증 정보 만들기 → OAuth 클라이언트 ID(또는 클라이언트 만들기)를 누릅니다.
  3. 애플리케이션 유형은 데스크톱 앱을 고릅니다. 웹 애플리케이션이 아닙니다.
  4. 이름은 아무거나 넣고 만들기를 누릅니다.
  5. 완료 창에서 JSON 다운로드를 눌러 파일을 저장합니다. 파일명은 client_secret_...json 형태입니다.

5. 앱에서 연결

  1. 메모 일정함 → 환경 설정 → Google Calendar로 갑니다.
  2. “OAuth 클라이언트 JSON”에서 방금 받은 파일을 선택합니다.
  3. Google 계정 연결을 누르고 로그인한 뒤 권한을 허용합니다.
  4. “Google에서 확인하지 않은 앱” 경고가 뜨면 고급 → 메모 일정함(안전하지 않음)으로 이동을 누릅니다. 본인이 만든 테스트 앱이라 나오는 정상 경고입니다.

알아둘 점

  • 게시 상태가 테스트이면 연결 토큰이 7일 뒤 만료되어 일주일마다 다시 연결해야 합니다. 귀찮으면 동의 화면에서 앱 게시(프로덕션으로 전환)를 누르면 됩니다. 본인 전용이라면 심사를 받지 않아도 "확인되지 않은 앱" 경고만 뜨고 계속 쓸 수 있습니다.
  • JSON 파일에는 클라이언트 비밀값이 들어 있으니 메신저나 메일로 공유하지 마세요. 앱은 이 파일을 Windows 계정으로 암호화해 저장하므로 연결이 끝나면 원본은 지워도 됩니다.
  • 여러 PC에서 쓰려면 같은 JSON 파일을 각 PC에서 한 번씩 선택해 연결하면 됩니다. 프로젝트를 새로 만들 필요는 없습니다.

캘린더를 고르려면 권한을 한 번 더 승인해야 합니다.

  1. Google Cloud에서 데스크톱 앱 OAuth 클라이언트를 만듭니다.
  2. 다운로드한 JSON 파일을 아래에서 선택합니다.
  3. Google 계정 연결 버튼을 눌러 권한을 승인합니다.

인증정보는 Windows 계정으로 암호화되어 이 PC에만 저장됩니다.
